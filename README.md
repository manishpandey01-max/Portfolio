# Manish Pandey - Personal Portfolio

A simple and beginner-friendly personal portfolio website created using **HTML and CSS**.
The website presents my introduction, qualifications, skills, learning journey, and contact information in a clean and minimal design.

## About the Project

This is my personal portfolio website where I showcase my basic web development skills and educational background.

I focused on creating a simple, clean, responsive, and easy-to-navigate website without using any complex frameworks or libraries.

## Technologies Used

### HTML5

HTML5 is used to create the structure and content of the website.

I used HTML for:

* Navigation bar
* Hero/Introduction section
* About section
* Qualifications section
* Skills section
* Learning Journey section
* Contact section
* Footer

I also used semantic HTML elements such as:

* `<header>`
* `<nav>`
* `<section>`
* `<footer>`

### CSS3

CSS3 is used to design and style the website.

I used CSS for:

* Colors and typography
* Spacing and alignment
* Buttons
* Qualification cards
* Skill tags
* Navigation styling
* Borders
* Hover effects
* Responsive layout

### Flexbox

CSS Flexbox is used mainly for:

* Navigation bar alignment
* Arranging skill tags
* Arranging contact links
* Creating flexible layouts

### Responsive Design

I used CSS media queries to make the website responsive and suitable for smaller screen sizes such as mobile devices.

## Features

* Clean and minimal design
* Responsive layout
* Navigation links to different sections
* About section
* Educational qualifications
* Skills and future goals
* Learning journey timeline
* Contact links
* GitHub and LinkedIn links
* Hover effects on buttons and links
